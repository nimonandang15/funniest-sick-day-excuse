# AGENT.md

Entry for the make.fun competition "The Funniest Sick-Day Excuse"
(https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

`main.ts` (Node 22, stdlib only) writes one original sick-day excuse line to
`/output/entry.txt` with no trailing newline, and enforces the gate itself:
1–200 characters, a single line, exactly one sentence, ASCII-only.

Run it with `node main.ts`. It exits 0 on success.
